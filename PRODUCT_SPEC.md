# Smriti Setu — Product Specification

## Overview
Smriti Setu is a cognitive support platform designed for elderly users with dementia, specifically targeting those in North Eastern India. It is built as an offline-first, elder-centric PWA with caregiver assistance.

## Roles
1. **Elder**: The primary user. The interface for elders is simple, calm, accessible, and resilient to lack of internet.
2. **Caregiver**: A supporting user who manages the elder's profile, monitors cognitive health, and customizes memories/games.
3. **Health Worker** (Future): Can view aggregated cognitive data and provide medical recommendations.

## Core Features
1. **Adaptive Cognitive Games**: Games designed to improve cognitive retention, dynamically adjusting to the elder's cognitive state.
2. **AI Personalization**: Interactions and game content are personalized based on the elder's profile and historical performance.
3. **Daily Assistance**: Reminders for medication, hydration, and daily tasks.
4. **Caregiver Monitoring**: Dashboards for caregivers to track cognitive changes, performance, and application usage.
5. **Elder-Friendly Interface**: Large tap targets, high contrast, clean layouts, and absence of complex navigation.
6. **Tap-to-Hear Voice Assistance**: Audio-first accessibility for users with visual or reading impairments.
7. **NER Cultural/Language Personalization**: Localization and cultural context specific to North Eastern India (English, Hindi, Assamese, Bengali).
8. **Offline-First Functionality**: Core features must work seamlessly without an internet connection.
9. **Memory-to-Game**: Converts the elder's personal memories and uploaded media into interactive cognitive exercises.
10. **Cognitive Digital Twin**: A data model representing the elder's cognitive state over time.
11. **Cognitive Change Radar**: Alerts caregivers to significant changes in cognitive performance or behavioral patterns.
12. **Relay Sync**: Architecture to seamlessly sync local data with the cloud when an internet connection becomes available.

## Design Philosophy
- **Calm**: Low cognitive load, no unnecessary animations or cluttered UI.
- **Trustworthy**: Secure, reliable, and consistent.
- **Mature**: Respectful design, avoiding childish aesthetics despite the game-like nature.
- **Accessible**: High contrast, large fonts, clear audio cues.
- **Warm**: Empathic and culturally resonant design elements.
