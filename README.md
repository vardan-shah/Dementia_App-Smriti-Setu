# Smriti Setu

Smriti Setu is an advanced prototype of an elder-first, caregiver-assisted, offline-first cognitive support platform for elderly dementia users, initially focused on North Eastern India.

## Features

- Adaptive cognitive games
- AI personalization
- Daily assistance
- Caregiver monitoring
- Elder-friendly interface
- Tap-to-hear voice assistance
- NER cultural/language personalization
- Offline-first functionality
- Memory-to-Game
- Cognitive Digital Twin
- Cognitive Change Radar
- Relay Sync

## Architecture

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, PWA, IndexedDB (Dexie.js), Zustand, TanStack Query, Zod.
- **Backend**: Node.js, TypeScript, Fastify, REST API, Zod.
- **Database**: Supabase, PostgreSQL.
